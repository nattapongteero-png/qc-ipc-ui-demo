# QC & IPC Criteria — UI Demo

หน้าตัวอย่างสำหรับรีวิว UI ของหน้า "เพิ่มเกณฑ์ QC & IPC" ในระบบ Herbal ERP

**เปิดดู:** https://nattapongteero-png.github.io/qc-ipc-ui-demo/

## นี่คืออะไร

เป็นไฟล์เว็บที่ build แล้ว (static) สำหรับให้ทีมกดลองใช้งาน UI โดยไม่ต้องติดตั้งอะไร

- ข้อมูลทั้งหมดเป็น **ชุดจำลอง** ไม่ได้ต่อกับฐานข้อมูลจริง
- กดปุ่ม CREATE แล้ว **ไม่มีการบันทึก**
- ไม่มีระบบ login และไม่มีเมนูด้านข้าง

## สิ่งที่ลองได้

- เลือก Stage (วัตถุดิบ / ระหว่างผลิต / ปล่อยผ่าน) แล้วดูว่าฟอร์มเปลี่ยนตาม
- เลือกหัวข้อทดสอบ แล้วดูตัวอย่างหน้าจอบันทึกผลของ operator
- กรอกค่าที่หลุดเกณฑ์ แล้วดูการ์ดเปลี่ยนเป็นสีแดง
- เปิด Multi-Stage แล้วโหลดแผนมาตรฐาน USP

## ที่มาของโค้ด

Build จาก source เดียวกับระบบจริง ไม่ได้คัดลอกโค้ดมาแยก
