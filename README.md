# Herbal ERP — UI Demo (QC / IPC / SOP)

หน้าตัวอย่างสำหรับรีวิว UI ของระบบ Herbal ERP

**เปิดดู:** https://nattapongteero-png.github.io/qc-ipc-ui-demo/

## นี่คืออะไร

ไฟล์เว็บที่ build แล้ว (static) สำหรับให้ทีมกดลองใช้งาน UI โดยไม่ต้องติดตั้งอะไร
เปิดจากมือถือหรือคอมก็ได้

- ข้อมูลทั้งหมดเป็น **ชุดจำลอง** ไม่ได้ต่อกับฐานข้อมูลจริง
- กดบันทึก **ไม่มีการบันทึกจริง** ปิดหน้าแล้วค่าหาย
- ไม่มีระบบ login

## หน้าที่กดดูได้ (ปุ่มสลับหน้าอยู่มุมขวาล่าง)

| หน้า | ดูอะไร |
|---|---|
| **SOP Execution** | การ์ดขั้นตอนการผลิต · เอกสาร SOP ของแต่ละขั้นตอน · การ์ด IPC ที่กดแล้วเด้ง Modal บันทึกผล |
| **IPC — บันทึกผล** | รายการเกณฑ์ IPC ทั้งใบสั่งผลิต กดที่การ์ดเพื่อบันทึกหรือดูผลที่บันทึกไว้ |
| **ใบสั่งผลิต — ดำเนินการผลิต** | ภาพรวมใบสั่งผลิต เป็นทางเข้าไปหน้า SOP กับ IPC |
| **สร้างเกณฑ์ QC / IPC** | หน้าตั้งเกณฑ์ พร้อม Live Preview ที่แสดงหน้าจอบันทึกผลของ operator |
| **ชุดการทดสอบ** | ผูกเกณฑ์เข้ากับสินค้าหรือหมวดสินค้า |

## สิ่งที่ลองได้

- กดที่การ์ด IPC ใบไหนก็ได้ → เด้ง Modal บันทึกผล เป็นหน้าจอเดียวกับที่เห็นใน Live Preview ตอนตั้งเกณฑ์
- เกณฑ์ที่บันทึกผลไปแล้ว จะเปิดดูประวัติการบันทึกได้ทั้งค่าทุกตัวอย่างและผลแต่ละรอบ
- กด "ดูเอกสาร SOP" ในแต่ละขั้นตอน เพื่ออ่านวิธีปฏิบัติงาน
- กรอกค่าที่หลุดเกณฑ์ แล้วดูการ์ดเปลี่ยนเป็นสีแดง
- หน้าตั้งเกณฑ์: สลับ Stage แล้วดูฟอร์มเปลี่ยนตาม · เปิด Multi-Stage แล้วโหลดแผนมาตรฐาน USP

## ที่มาของโค้ด

หน้า SOP Execution และหน้า IPC ในเดโมนี้คือ **หน้าเดียวกับในระบบจริง** ไม่ได้ทำเลียนแบบขึ้นมาใหม่
สิ่งที่เปลี่ยนมีแค่สองอย่างที่เว็บ static ทำเองไม่ได้ คือการเรียก API (ใช้ข้อมูลที่ freeze ไว้แทน)
และ component ของ DevExtreme ซึ่งลิขสิทธิ์ห้ามแจกจ่ายต่อ (เปลี่ยนเป็นของธรรมดาที่หน้าตาเหมือนกัน)
